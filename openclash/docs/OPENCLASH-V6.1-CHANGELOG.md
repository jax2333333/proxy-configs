# OpenClash v6.1 配置重构记录

版本：v6.1
状态：Production Ready

## 一、版本目标

v6.1 在 v6 架构基础上进行策略组减法重构：

- 简化日常使用入口
- 保留 Smart 自动选择能力
- 双机场独立管理
- 将测速功能从日常选择中分离
- 提升长期维护和故障排查效率

## 二、核心架构变化

### 删除旧结构

移除：

- ♻️智能选择
- ♻️AI智能选择
- 🌐全部节点
- 地区测速策略组

原因：

测速和底层节点管理不应该暴露为日常选择入口。

## 三、新策略架构

核心入口：

```
🔮 节点选择
```

结构：

```
A|智能选择
B|智能选择

🇭🇰 A|香港智能
🇭🇰 B|香港智能

🇯🇵 A|日本智能
🇯🇵 B|日本智能

🇹🇼 A|台湾智能
🇹🇼 B|台湾智能

🇺🇸 A|美国智能
🇺🇸 B|美国智能

🇸🇬 A|新加坡智能
🇸🇬 B|新加坡智能

🖐️ 手动选择
🛠️ 节点测速
🚀 直连
```

## 四、Smart策略

新增：

- A|智能选择
- B|智能选择

类型：

```
smart
```

作用：

- A机场全部节点智能选择
- B机场全部节点智能选择

## 五、地区智能

保留地区：

- 香港
- 日本
- 台湾
- 美国
- 新加坡

取消：

- 韩国
- 英国
- 德国

每个机场保持独立地区 Smart：

例如：

```
🇯🇵 A|日本智能
🇯🇵 B|日本智能
```

## 六、维护策略组

### 🛠️ 节点测速

类型：

```
url-test
```

用途：

- 晚高峰测试
- 节点质量评估
- 故障排查

不作为普通应用默认出口。

### 🖐️ 手动选择

类型：

```
select
```

来源：

- Airport-A
- Airport-B

包含：

```
🚀 直连
```

用途：

- 临时切换出口
- TikTok测试
- 流媒体测试
- 特殊IP需求

## 七、应用策略调整

### AI

保留：

- 日本
- 新加坡
- 美国
- 台湾

排除：

- 香港

原因：部分 AI 服务对香港出口兼容性不稳定。

### TikTok

增加：

- 🔮节点选择
- 🖐️手动选择
- 台湾智能
- 新加坡智能
- 美国智能
- 日本智能

原因：TikTok 对出口地区敏感。

### Microsoft / OneDrive

调整：

第一优先：

```
🚀直连
```

## 九、安全规则

禁止提交：

- 真实机场订阅 URL
- UUID
- Token
- 密钥
- 密码
- Cookie
- API Key

真实机场信息仅保存在本地覆写环境。

## 十、后续维护原则

- main 是唯一正式版本
- 修改前重新读取 GitHub main 最新文件
- 默认只修改 openclash/
- 不根据聊天历史覆盖当前配置
- 所有架构调整必须经过 YAML 和规则引用验证
