# Shadowrocket DIRECT 策略组缓存异常记录

## 故障现象

出现“本应直连流量走代理”的情况：

```text
🌐 全球直连
  ↓
DIRECT
  ↓
基础代理节点
```

配置文件语法检查正常，规则本身没有错误。

## 根因定位

确认不是 `[Rule]` 顺序问题，而是 Shadowrocket 策略组状态缓存异常。

当策略组长期修改、成员调整、配置覆盖更新后，Shadowrocket 可能保留旧策略组成员关系，导致：

```text
🌐 全球直连 = select,DIRECT
```

实际运行状态中仍残留旧代理节点引用。

## 修复方式

不要直接修改规则。

执行：

1. 打开 Shadowrocket 配置。
2. 删除 `🌐 全球直连` 中原有 `DIRECT`。
3. 保存并重新加载配置。
4. 在本地策略组重新添加 `DIRECT`。
5. 测试国内服务是否恢复直连。

验证结果：

```text
🌐 全球直连
  ↓
DIRECT
```

恢复正常。

## 排查顺序

以后遇到：

```text
直连流量 → 代理节点
```

优先检查：

1. 策略组成员是否异常残留。
2. 删除并重新添加 DIRECT。
3. 完全重新加载配置。
4. 删除旧配置重新导入 Raw。
5. 最后再检查 Rule 命中。

不要第一时间修改：

- GEOIP,CN
- FINAL
- 国内规则
- DNS

## 当前设计保持

移动版配置保持：

```ini
🌐 全球直连 = select,DIRECT

FINAL,🎯 节点选择
```

设计目标：

- 明确国内服务 DIRECT。
- 未匹配国外服务进入代理兜底。
- 不通过修改 FINAL 解决误代理问题。

## 维护分类

Shadowrocket

└── 策略组异常

    └── DIRECT 被代理节点污染

        ├── 删除策略成员
        ├── 重新添加 DIRECT
        └── 重新加载配置
